# S.H.I.E.L.D. Command Center // Global Defense Grid

A high-performance, futuristic Marvel S.H.I.E.L.D. Command Center dashboard built with **React**, **TypeScript**, **Tailwind CSS**, and **HTML5 Canvas**.

---

## ⚡ Key Improvements & Enhancements

1. **Buttery-Smooth 60-FPS 3D Earth Globe**:
   - Resolved the previous CPU bottleneck (which computed 115,600 ray-tracing iterations per frame).
   - Re-engineered with high-performance orthographic spherical vector projection, deep ocean gradient base, multi-layered landmass contours, atmospheric rim lighting, starfield, and animated ballistic orbital arcs with traveling photon pulses.
   - Interactive orbit controls: drag to rotate with momentum, scroll to zoom, HUD grid toggle, and click-to-select crisis beacons.

2. **Crisp Cyber-Tactical Visual Polish**:
   - Elevated from muted gray tones to an ultra-clean **S.H.I.E.L.D. Aero-Tactical Interface**: deep obsidian space canvas (`#070A10`), cybernetic glass panels (`#0D1424`), and vibrant HUD accents:
     - **DEFCON 5 / Catastrophic**: `#EF4444` Crimson
     - **Tactical Orange**: `#FF6A1A`
     - **Vibranium Cyan**: `#00F0FF` / `#38BDF8`
     - **Quantum Emerald**: `#10B981`
     - **Asgardian Gold**: `#F59E0B`
   - Chamfered edges, military grid overlays, glowing status tags, and sharp telemetry badges.

3. **High-Fidelity Audio Synthesis**:
   - Web Audio API synthesizer with non-blocking browser gesture unlock.
   - Distinct sound effects for UI clicks, alarm klaxons, tactical dispatch chords, mission victory chimes, and failure warnings.

4. **Avengers Collectible Dossier Cards (Series 2)**:
   - 3D tactile flip animation:
     - **Front**: Holographic tier frame (Omega, Legendary, Epic, Elite), calculated Power Level index (0-100), glowing avatar aura, power tags, readiness indicator, and quick "Draft Squad" button.
     - **Back**: 7 segmented skill meters, classified S.H.I.E.L.D. dossier factoid, completed mission count, and geographic origin.

5. **Tactical Team Builder & AI Auto-Assemble**:
   - Interactive **7-Axis Tactical Capability Radar SVG** comparing squad capabilities against threat requirements.
   - Real-time **Tactical Gap Analysis** with instant warnings for missing capabilities.
   - AI Auto-Assemble algorithm optimizing for skill fit, geographic proximity, and hero stamina.
   - One-click preset formations: *Original Six*, *Space Response*, *Stealth Ops*, *Cosmic Vanguard*, and *Mystic Guard*.

6. **Live Simulation Engine & Multi-Tier Roles**:
   - Automated crisis spawner with sound alerts.
   - Active missions progress engine with probabilistic outcome resolution and hero recovery.
   - Role permissions: **Director** (full override, escalation, manual threat creation), **Operator** (tactical dispatch), and **Viewer** (read-only monitoring).

## 🚀 Getting Started

To run the application locally:

```bash
npm run dev
```

To build for production:

```bash
npm run build
```
